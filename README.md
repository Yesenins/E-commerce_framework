# E-commerce Framework

## Description

The project focuses on testing the website [Lamoda.by](https://www.lamoda.by), an online store for clothing, footwear, and accessories.
Testing covers the UI (search, cart, personal account) and includes automated tests in Java using Selenium.

**Goals**:
- Verify registration, login to the personal account, and cart management.
- Ensure the correct functionality of search and filtering in the product catalog.

## Technology Stack

- **Programming Language**: Java 17
- **UI Testing**: Selenium 4.28.1
- **Testing Framework**: TestNG 7.4.0
- **WebDriver Management**: WebDriverManager 5.9.3
- **Reporting**: Allure 2.28.1 (with TestNG integration)
- **Build**: Maven (with Surefire Plugin 3.5.2)
- **Logging**: Log4j 2.20.0

## Requirements

- JDK 17 or higher
- Maven 3.8.0 or higher
- Browsers: Chrome, Firefox (with ChromeDriver/GeckoDriver)
